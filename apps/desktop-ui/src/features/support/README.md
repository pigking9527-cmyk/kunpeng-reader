# 关于与支持端口

此目录是正式“关于与支持”界面的 UI 和端口契约。组件不直接调用 Tauri、读取本机存储或持有附件字节；所有文件、诊断快照和网络请求由 `SupportPort` 的实现管理，UI 只保留不透明附件 ID 和必要的展示元数据。

## 已覆盖的正式行为

- 读取当前版本、手动检查更新、通过端口打开更新页；失败消息固定，不显示服务端或本机错误详情。
- 读取并缓存当前版本的 Markdown 更新说明；发现更新时保留其说明，并可按版本保存“忽略更新”选择。说明始终以文本交给 UI，不能作为 HTML 注入。
- Bug 与功能建议、最多三张 JPEG/PNG/WebP 截图（每张最大 1 MB）、Bug 专用的脱敏问题记录；功能建议在 TypeScript 类型层不能携带问题记录。
- 可把脱敏问题记录直接保存到桌面。Rust 返回的绝对路径不会从端口泄露给调用方；上传成功、显式移除或保存后均应释放不透明附件的内存字节。
- 读取及导出脱敏诊断；安全模式先要求确认，并明确说明它关闭后台任务但不会删除书籍或账户数据。
- 所有请求接受 `AbortSignal`。用户取消会立即恢复 UI 并忽略迟到结果；端口实现仍必须尽可能停止底层工作。

## 保留给端口接入与人工验收的项目

- 原生端必须在附件读取、图片压缩、诊断捕获、导出、更新页打开和反馈上传处重复校验格式、大小、URL 和权限；UI 校验不作为安全边界。
- 使用真实的测试账号手测：更新网络失败、反馈上传成功/失败、文件选择取消、截图/问题记录移除、导出位置、安全模式确认/取消、关闭页面时请求尚未完成。
- `SupportPort` 已具备遗留更新卡片的“忽略此版本”、发布说明和问题记录“保存到桌面”能力；正式页面接入时仍须逐项做离线、取消、保存与回退人工验收后，才能删除遗留入口。
