# 认证与同步 API 基址

当前认证与同步 API 的唯一公开基址是 **`/v1`**。

- 新客户端使用 `/v1/auth/*` 与 `/v1/sync/*`。
- 客户端不发送世代请求头，服务端也不按应用版本号判断准入。
- 历史 `/auth/*` 与 `/sync/*` 不映射业务处理器，在认证、数据库访问和请求体解析前
  返回 HTTP 426 与 `CLIENT_UPGRADE_REQUIRED`。
- `/health`、公开更新元数据与反馈接口不属于认证/同步 API，可以继续保持无前缀路径。

API 基址与 `syncProtocolVersion` 相互独立：前者隔离服务入口，后者描述同步数据语义。
当前破坏性开发基线为协议 v5；见 [`api-v5.md`](api-v5.md)。
