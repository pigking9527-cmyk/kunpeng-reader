## 使用规则

1. 开始会修改多个文件、共享契约或原生层的任务前，先阅读本文件与 `git status --short`。
2. 在下表登记会话/分支、任务范围和预计触及的目录或文件；不要登记私密资料。
3. 已被占用的文件默认不得并行修改。需要协作时，先拆分到互不重叠的文件或由同一会话串行合并。
4. 完成后记录提交（或明确“未提交，原因”）和验证结果，再删除该行。
5. 影响协议的任务必须先完成 ADR 和 `contracts/`，不能只登记在此文件。
