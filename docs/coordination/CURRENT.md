## 协议基线

- `syncProtocolVersion`：**1（契约抽取阶段）**。
- 现有桌面同步服务与桌面客户端是当前行为基准；schema/fixtures 尚未接入运行时校验，后续修改需先与真实服务端实现逐项对齐。
- 同步范围：阅读进度与续读位置、书签、高亮、批注、评分、用户标签、书单、生词本、阅读统计，以及可选的 `model_book_tags_v1` 自动书目维度标签。用户开启“同步智读历史”后，还包含单书与书库问答记录；书库记录不包含来源原文或本机书籍 ID。
- 不同步：图书正文/原文件、原始封面、语义模型、语义索引和本机路径。API Key/翻译凭据默认不同步；仅用户设置同步密码并开启密钥同步后，才以端到端加密密文同步。同步密码不可找回；忘记后通过服务端密钥包世代撤销旧密文，再以新密码重新加密。

## 当前跨端工作项

1. 为现有服务端 API 和同步实体补齐正式 schema、请求/响应 fixture 与兼容测试。
2. Android/iOS 先实现本地阅读、进度、高亮、书签、标签与书单；语义索引、智读和脑图不阻塞第一阶段。
3. 当前正式同步地址为 `https://117.72.220.69`；桌面公共发行版在本机没有历史配置时使用该默认值，自托管用户已保存的地址仍优先。Android/iOS 使用同一 HTTPS 端点，不得在生产版放开明文 HTTP。
4. 继续明确认证/Token 生命周期，并为将来从 IP 端点迁移到稳定域名准备兼容方案。
5. `model_book_tags_v1` 由 ADR-0004 定义：与用户手工标签分离且始终同步；书库问答始终使用它，“使用大模型分类的标签”仅控制本机问答范围筛选。旧客户端必须忽略但保留该可选实体。
6. `ai_reader_history_v1/library-v1` 由 ADR-0005 定义：书库问答本机自动保存；只有用户开启“同步智读历史”才上传问题、回答和脱敏的来源索引。单条删除以不含正文的条目墓碑同步，避免旧设备复活已删历史。
