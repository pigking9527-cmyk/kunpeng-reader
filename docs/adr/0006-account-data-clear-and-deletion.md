# ADR-0006：本机清除、云端数据重置与账户删除

## 状态

已接受，2026-08-06。

## 决定

鲲鹏阅读器把破坏性操作拆成三个明确范围，不能用“退出登录”或“删除账号”代替数据清理：

1. **清除此设备数据**：删除应用专属配置、数据库、缓存、索引、模型、下载字体与本机凭据，并清空 WebView 本地存储；不删除用户从外部路径导入的 EPUB、PDF、MOBI、AZW3、TXT 等原始书籍文件。
2. **清除此设备及云端数据**：验证当前账户密码后，服务端删除该账户全部同步实体、递增 `data_generation` 并撤销该账户全部登录令牌；客户端随后执行同样的本机清除。
3. **删除账号**：同时验证当前账户密码和完整账号名，永久删除账户、同步实体、令牌、验证邮箱、一次性验证码、私密密钥世代和数据世代；客户端随后清除此设备数据。

`data_generation` 从 1 开始。认证、拉取、库存和写入响应返回当前世代；新版客户端在 `push` 与 `reconcile` 请求中携带世代。账户从未重置时，服务端继续接受未携带世代的旧客户端；一旦用户主动执行云端清除，世代大于 1，服务端必须拒绝缺失或不匹配世代的写入。这样旧设备即使仍保留离线数据，也不能把已经清除的数据重新上传。

云端清除撤销所有令牌，包括发起请求的令牌。客户端成功后保持退出状态；其他设备也必须重新登录。新版客户端若发现本机已有同步实体、但服务器世代与本机记录不一致，应拒绝接管新世代，并提示先清除此设备数据。不得自动把旧本地实体标记为新世代。

## 兼容性

- `syncProtocolVersion` 维持 1：新增字段和端点是可选扩展，未执行数据重置的既有账户行为不变。
- 用户执行云端清除后，旧客户端被有意阻止写入；这是该破坏性操作的安全条件，不允许降级为“清空后仍接受旧数据”。
- 客户端必须忽略未知响应字段；服务端对世代 1 继续兼容旧请求。

## 回滚与恢复

- 本机清除不可撤销，但不触碰书籍原文件；用户可重新导入原文件。
- 云端清除不可通过旧客户端回滚。服务端不得降低 `data_generation`，数据库备份恢复也必须保留较大的世代。
- 删除账号不可撤销；同名账号以后可重新注册，但获得新的用户 ID，与旧数据没有关联。
