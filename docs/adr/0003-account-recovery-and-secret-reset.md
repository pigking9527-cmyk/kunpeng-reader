# ADR 0003：账户找回与私密同步密码重置

**状态：已采纳（2026-07-29）**

## 决定

1. 同步账户密码只能通过已验证的绑定邮箱重置。邮箱验证、找回令牌和密码修改均由同步服务端处理；密码本身始终使用 scrypt 哈希保存。
2. 反馈邮箱投递与账户安全邮件使用独立环境变量配置。反馈 SMTP 能力不是邮箱所有权证明，不能自动成为账户找回通道。
3. 智读/翻译的“同步密码”不提供找回。它从不上传、从不由服务端保存，服务端也无法解密 API Key 密文。
4. 用户可在仍登录的设备上用新同步密码重新加密本机的 API Key；若忘记同步密码，选择“遗忘并撤销云端密钥包”。服务端提升该账户的 `secretBundleEpoch`，写入旧包墓碑，并拒绝任何旧世代包的后续上传。
5. 新密钥包使用 `secret_bundle_v1/default`，在 AES-GCM 信封中携带 `epoch`。旧的 v1 信封只在服务器世代为 1 时兼容读取；重置后必须重新加密。

## 后果

- 找回账户密码前，用户必须先在一个已登录设备绑定并验证邮箱；未绑定邮箱的账户不能被“客服重置”。
- 忘记同步密码不会删除本机现有智读/翻译配置，但云端旧密钥包被永久撤销。用户输入新同步密码并重新加密后才会恢复跨设备密钥同步。
- 所有客户端必须忽略未知私密同步字段，并在收到旧世代冲突时采用服务端墓碑，不能重复上传旧密文。

## 安全边界

- 邮箱验证码/重置令牌仅保存不可逆摘要，15 分钟有效、单次使用，并同时受 IP 与账户限流。
- 重置账户密码会撤销该账户全部旧登录 token，再签发当前设备的新 token。
- API Key、同步密码、验证码、重置令牌均不得写入日志、fixture、Git 或反馈邮件。
