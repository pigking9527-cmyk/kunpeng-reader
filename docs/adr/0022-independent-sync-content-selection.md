# ADR-0022：同步内容独立选择（协议 v2）

## 决定

同步协议升级为 `syncProtocolVersion: 2`。原 `book_state_v2` 的用户数据拆分为：

- `reading_progress_v1`：阅读进度、续读位置和每日进度历史；
- `reading_data_v1`：书签、高亮、批注和评分；
- `reading_statistics_v1`：单书累计阅读统计；小时桶 `reading_bucket_v2` 仍同属统计分类。

用户标签和收藏夹继续为独立实体，但与阅读资料使用同一个选择项。每个显示的同步项是本机的真实交换过滤器。关闭后不会上传、下载、软删除或清空已存副本；重新开启时重置本机同步 cursor，从云端重新拉取。

## 影响与回滚

这是早期开发期接受的破坏性升级，不兼容协议 v1 客户端。`book_state_v2` 仅用于本机一次性升级种子，不再由 v2 上传或下载。若要回滚到 v1，必须从升级前备份恢复，并恢复 v1 客户端与服务端允许的实体清单；不得把拆分实体静默合并回旧云端记录。
