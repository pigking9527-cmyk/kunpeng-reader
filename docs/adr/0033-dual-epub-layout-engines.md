# ADR-0033：单一阅读页中的双 EPUB 排版引擎

## 状态

已接受（2026-08-13）。

## 决定

- 阅读页仍只有一套用户可达 UI，`epubLayoutEngine` 只切换该页内的排版策略：`legacy` 或 `modern`。
- 缺失或非法值一律归一为 `legacy`；该设置仅影响 EPUB，PDF 忽略。
- `legacy` 保留现有逐行虚拟页、遮罩和连续图片预览兼容路径。
- `modern` 的分页使用浏览器原生 CSS 多栏，滚动使用真实连续 DOM 文档流，媒体使用等比限宽限高与 `break-inside: avoid`。它不创建图片克隆或文字虚拟页。
- 引擎切换先记录源文本字符锚点，重新加载当前章原始 HTML，再在新布局恢复锚点；不直接复用另一策略已处理的 DOM。

## 兼容性

`epubLayoutEngine` 位于 `app_settings_v1` 顶层，为可选字段。旧客户端会忽略并由合并层保留它；新客户端对缺失值按 `legacy` 处理，因此不提升同步协议版本。

## 开源参考边界

实现参考 Foliate、Readium CSS 和 epub.js 的公开架构思路，但不引入它们的解析器、依赖或源码；项目自行实现所需的布局策略。
