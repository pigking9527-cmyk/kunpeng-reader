# ADR-0037：情报主机端到端加密推理中继

- 状态：已接受（契约先行，尚未实现运行时）
- 日期：2026-08-24

## 背景

客户端需要在本机 8B 模型不足时，使用用户自己的情报主机完成跨书问答、深度阅读和资讯偏好
判断。但把正文或模型输入放进现有同步实体、公开资讯分发包，或以服务端明文 RPC 转发，都会
违反“正文/模型/向量索引不进入同步”和用户本机档案边界。

## 决定

1. 使用独立 `/v1/intelligence/host-*` API 与 `contracts/intelligence/host-inference-v1.*`，不复用
   `/v1/sync/*`、`sync_entities_v4` 或 `PublicationBundleV1`。
2. 客户端和已配对主机用 HPKE 端到端封装请求/结果；服务端只做账号隔离、安装绑定 capability
   授权、状态路由、TTL 和删除，不能解密或搜索任务内容。
3. 配对由同账号的短时一次性邀请、公钥指纹确认和可撤销 host capability credential 组成。普通
   Bearer token 无法伪装发布/处理主机；能力使用固定 operation 枚举和 revision，而不是提示词。
4. 服务端任务请求默认 15 分钟、最多 60 分钟；结果最多 24 小时。ACK、取消、撤销或过期后
   删除密文。取消和撤销优先于结果上传。
5. 该能力默认关闭，作为“我的情报主机”路由的可选后端。客户端无主机、无独显或离线时仍可
   使用本地模型、云端（若用户配置）或关闭，不改变现有同步和公开资讯流。

## 兼容性影响

不改变 `syncProtocolVersion`：这是独立、可选的 API。旧客户端和未实现端点的客户端不能请求
中继；它们继续忽略未知能力，不应丢失同步数据或公共资讯。

## 替代方案

- **将任务作为同步实体**：拒绝。同步会保留、冲突合并和跨设备复制，不适合短时私有推理内容。
- **服务端解密后转发 HTTP**：拒绝。服务端会接触正文/提示词/答案，并形成永久敏感数据面。
- **直接暴露用户主机公网端口**：拒绝。会增加 NAT、证书、攻击面和移动端可达性问题。

## 迁移与回滚

先部署 schema/fixture 与 feature gate，再实现服务、主机和客户端。回滚关闭 gate、撤销 capability
credential、终止长轮询并销毁未完成的任务/结果密文；不触碰同步实体、本机书库、模型或公开资讯。

## 验证

静态契约测试必须覆盖无明文字段、配对能力约束、请求/结果 key direction、TTL、取消与 status
终态。运行时实现后必须补跨进程端到端互操作、篡改/AAD 重放、跨账号隔离、取消竞态、到期物理
删除、日志审计和数据库迁移 E2E；在这些证据完成前不得宣称该中继可用或部署。
