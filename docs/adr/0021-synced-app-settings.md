# ADR-0021：桌面软件设置同步

- 状态：部分被 ADR-0031 取代（历史记录）
- 日期：2026-08-08

## 决定

> 本 ADR 记录协议 v1 至 v4 时的兼容设计。ADR-0031 已在协议 v5 明确移除
> `readerJumpBackSizeLevel` 和所有 1–10 级转换/镜像要求；下文相关段落仅保留历史背景，
> 不得作为 v5 实现依据。

Windows、Linux 与 macOS 桌面端使用可选同步实体 `app_settings_v1/default` 保存账户级、非敏感的软件设置。实体沿用现有 LWW 顺序（`updated_at`、`sync_version`、`device_id`），不进入离线核心迁移包，也不包含路径、密钥、书籍内容或平台专属运行状态。

首批字段包括阅读页中部“跳转回退”功能的开关、自动隐藏方式、秒数、翻页数、图标大小和图标位置。新客户端以 `readerJumpBackIconSizePx` 保存 30–160 px 的整数大小（步进 1 px）；原 `readerJumpBackSizeLevel` 继续作为旧客户端的 1–10 级兼容镜像，绝不复用为像素值。读取旧 payload 时客户端按旧线性规则转换级别；新客户端写回时同时写入最近的兼容级别。位置使用 `readerJumpBackPositionX` / `readerJumpBackPositionY` 两个 0–1000 的整数，和手势提示一样映射为图标左上角在可见区域内的完整轨道：0 和 1000 分别贴齐左/上与右/下边界。这样图标不会越界，且整段拖动范围都均匀可调；缺失字段按旧版默认右侧中部（950, 500）读取。

同一 `v1` payload 还允许两组独立的账户偏好：

- `newsSourceIds`、`newsTiebaBars` 与 `newsEnabledTiebaBars`：资讯页选中的内置来源、自定义贴吧名称及启用状态。来源目录不设置产品层的选择上限；同步载荷仅以 1024 个 ID 作为防损坏边界，足以容纳当前全部内置目录。自定义 RSS/Atom 的地址和定义不进入这个软件设置实体，也不包含资讯正文、缓存、文章 URL、阅读记录或版式排序。
- `libraryAnswerLength`、`libraryHistorySyncMode`、`libraryAnswerFontSize` 与 `libraryLongContextEnabled`：书库问答的回答长度、历史同步策略、回答字号和 BGE-M3 长文精读偏好。语义模型、索引、模型文件和运行时能力仍只在本机保存；目标设备未准备 BGE-M3 时只保留偏好，准备完成后才可实际启用。
- `toolbarIconSizePx`、`toolbarItemOrder` 与 `toolbarHiddenItems`：主窗口顶部功能菜单栏的按钮高度（28–52 px）、完整排序和用户隐藏项。`toolbarContentVisible` 可选择只显示图标、只显示文字或两者同时显示，且至少保留一项；`toolbarContentOrder` 固定包含 `icon` 与 `text`，通过拖动决定按钮内部是图标在前还是文字在前。缺少新字段的旧 payload 默认仅显示图标、图标在前，保证升级后界面不会突然变宽。菜单项排序集合固定为账户、搜索、统计、书库问答、资讯、情报中心、收藏夹、筛选与布局、设置和更多菜单；`settings` 始终在排序集合中且不得隐藏。账户、情报中心和收藏夹入口均可排序、可隐藏、并随菜单栏尺寸缩放；窗口拖动区域与最小化/最大化/关闭仍属于窗口框架。客户端在本地设置页拖动后立即重排，并以短暂位移动画让相邻按钮避让；减少动态效果时直接重排。缺少账户、情报中心或收藏夹的旧排列在读取时按当前默认相对位置补齐。收藏夹入口的排列属于账户级界面偏好，但收藏内容不进入本实体：书单成员继续使用既有书单/集合实体，情报新闻收藏当前仅在本机保存有界公开元数据。
- `gestureSettings`：自定义右键手势的总开关、1–10 全局精度、最多 24 条手势档案，以及提示的开关、字号、背景、透明度和相对位置。每条档案只保存名称、动作、作用范围、独立精度和 48 个归一化轨迹点；不保存书籍正文、本机路径、页面历史或当前窗口状态。`undo_last` 是恢复最近关闭页面或最近阅读跳转的规范动作；旧的 `reopen_last` 和仅限阅读页的 `restore_jump` 仍可读取，并在下次写回时归一为 `undo_last`。手势档案和提示设置作为一个低频设置组按 LWW 同步，目标端在拉取完成后立即写入本机缓存并广播给已打开的阅读窗口。新写入 `profilesInitialized: true`；它使空档案列表成为明确清空。缺少该标记的旧空列表属于迁移歧义，不能擦除本地已录制的手势。
- `readerLayoutSettings`：全局阅读排版和分页偏好，包括字体选择、样式模式、简繁、正文字号、注释字号、行高、段距、字距、四边页距、图片跨页规则、单双页/滚动、双页中缝与翻页效果/速度。按书独立外观覆盖不进入该组；字体文件也不上传，目标端缺少可选字体时保留选择并使用当地后备字体。客户端对数值和枚举做边界校正，滚动模式强制单页。

客户端以字段补丁写回：只更新本次所属设置组，合并时保留其余已知及未知字段，避免资讯、书库问答和阅读页的独立界面互相重置。

协议 v5 另使用两个独立的可选实体，避免把高频阅读上下文或用户自定义地址隐式塞进软件设置：`reading_handoff_v1/default` 只保存当前阅读的内容 ID，跟随“阅读进度与续读位置”；`news_subscriptions_v1/default` 只在用户显式开启“自定义 RSS / Atom 订阅（可选）”后保存至多 200 条已验证 HTTPS 地址。二者都不携带书籍文件、本机路径、资讯正文、缓存或浏览历史；关闭开关只暂停交换，不删除副本。

## 兼容性

这是同步协议 v1 的可选扩展，不提升 `syncProtocolVersion`。旧客户端不认识该实体时必须忽略而不能删除；认识 v1 的客户端对未知字段执行读后保留。服务器允许未知字段，但校验已知字段的类型与边界。

若账户尚无 `app_settings_v1/default`，客户端以当前本机设置创建实体，不能用默认值覆盖已有本机偏好。首次接入一个账户时，云端已有的该实体必须先于 WebView 启动期间写入的本机默认值落地，避免新时间戳错误地在 LWW 中压过云端设置。拉取同步完成后，已打开的阅读窗口应重新读取实体并立即应用。

## 后果

该实体很小，硬件与流量成本可忽略。整个设置对象按 LWW 合并，适合低频软件偏好；未来若出现需要逐字段并发合并的高频设置，应拆成独立实体或升级版本，而不是复用字段表达新语义。
