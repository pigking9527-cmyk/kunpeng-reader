# ADR-0020：阅读背景图使用独立二进制资产

- 状态：已接受
- 日期：2026-08-08

## 决定

`reader_palette_v1` 不再在新客户端写入 `backgroundImage` Base64。主题只保存 `backgroundAssetId`、`backgroundAssetSha256`、`backgroundAssetMime` 和 `backgroundAssetBytes`；ID 等于 SHA-256 十六进制摘要。客户端先把导入图片保存至本机缓存，上传资产成功后再推送引用主题；拉取主题后先下载并校验资产，再把短的本机 `reader` 资源 URL 交给阅读页。

资产 API 需要同步账号认证与邮箱验证，单图最大 10 MiB、单账号最多 10 个活动背景资产，使用 1 MiB 顺序分块上传（服务端持久化已接收偏移以支持断点续传）和 HTTP Range 下载。资产计入账号存储及每日写入预算；清云端与删账号同时物理删除资产和未完成上传。

## 兼容性

协议仍为 v1 可选扩展。服务端继续读取旧 `backgroundImage` data URL；新版桌面端在首次读取或保存旧主题时，将其转为本机缓存和资产引用，并把旧字段清空。旧客户端可忽略新字段，但不能覆盖未知字段。

## 后果

同步负载不再含十兆级 JSON，阅读页初始化、消息传递和动态 CSS 不再承载 Base64 原图。代价是需要维护资产缓存、上传断点、下载校验和垃圾回收。
