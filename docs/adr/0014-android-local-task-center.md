# ADR-0014：Android 本机后台任务中心

日期：2026-08-07

## 状态

已采纳（Android M1）。

## 背景

桌面端已有后台任务状态与取消控制。Android 已有空闲全文索引、可续建的语义索引、Download/外部打开导入和本机恢复点，但此前只有分散的运行中布尔值，用户无法在一个位置看到其边界，也无法区分“可取消”和“当前原子操作不能中断”。

## 决定

Android 使用进程内、会话级的 `LocalTaskCenter`：

- 仅登记固定任务类型：全文索引、语义索引、Download 自动导入、外部打开导入、本机恢复点。
- 每条快照只含随机本机任务 ID、固定类型、状态、固定阶段、限制到非负上限的数值进度、粗粒度错误类别和开始时刻；不允许书名、正文、内容 ID、路径、URI、Token、请求/响应或原始异常进入快照或页面。
- 不写入 SQLite 同步实体、核心状态迁移包或恢复点；不触发网络请求；进程退出后历史自动遗失。设置“高级”提供任务中心入口。
- 全文索引和语义索引显示取消。按钮只设置取消请求；工作者在安全检查点才变为取消。全文在缓存原子写入前检查，语义在书/批次边界检查，并删除当前书的未完成向量与标记，避免发布部分结果；此前完成书籍仍可由既有 per-book 标记续建。
- Download/外部打开导入和恢复点不显示取消。它们依赖原生队列、SQLite 确认或私有文件原子交换，页面明确显示“当前原子步骤不能安全中断”。本 M1 不提供暂停，因为全文与语义的安全恢复语义分别是“下次重建缺失缓存”和“语义索引续建”，不是同一个可承诺的暂停/恢复任务协议。

## 后果

任务页面是隐私边界内的观察与真实取消入口，不是持久 JobScheduler，也不取代 Android 通知。后续若引入跨进程/前台服务任务，必须新增本机持久队列 ADR，并重新定义崩溃恢复、权限和通知语义；不得复用此会话 ID 作为同步字段。
