# ADR-0002：可选私密 AI 数据同步

## 决定

智读与翻译采用分层同步：非敏感服务配置默认同步；智读历史默认只保存在本机；API Key、翻译密钥默认永不上传。用户设置同步密码并明确开启后，密钥会在客户端使用 PBKDF2-HMAC-SHA256 派生密钥、AES-256-GCM 加密成单一密钥包后再作为同步实体上传。服务器仅保存密文，不能读取明文。

## 实体

- `ai_reader_config_v1`：服务商、接口地址、模型名；不含 API Key。
- `translation_config_v1`：已启用翻译服务的非敏感偏好；不含凭据。
- `ai_reader_history_v1`：按图书内容 SHA-256 分组，云端按账号跨书合计保留最近 100 条智读问答；默认关闭。每本书的本机历史仍独立保存，超出账号云端上限的旧记录不再物化为同步实体。
- `secret_bundle_v1`：加密的智读/翻译凭据；默认关闭，且只能通过同步密码在本机解锁。

删除沿用现有同步墓碑语义。所有端必须未知实体安全忽略；图书正文、原文件和原始封面仍不参与同步。

## 兼容性

协议版本维持 v1：新实体是可选扩展，旧客户端会忽略。移动端在支持前不得将这些实体删除或以空数据覆盖。
