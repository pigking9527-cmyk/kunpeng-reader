# ADR-0019：验证邮箱、账户资源预算与持久化滥用防护

## 状态

已接受。

## 决定

新注册账号可以完成登录和账户安全设置，但在其绑定邮箱验证码验证成功前，所有 `/sync/*` API 必须以 HTTP 403 和 `EMAIL_VERIFICATION_REQUIRED` 拒绝。已有账号在迁移时标记为已验证，以免无故中断既有同步；运营人员可通过只在服务器本机运行的管理工具封禁账号，封禁会撤销令牌并以 `ACCOUNT_DISABLED` 拒绝后续访问。

每个账号记录持久化资源预算：当前实体 JSON 与同步资产计入存储总额；实际接受的实体版本同时计入每日字节和实体写入额度。拒绝、冲突和重复投递不消耗每日额度。拉取、断点恢复下载和新设备从已有云端状态恢复不计入每日写入额度。新账号默认存储 25 MiB、每日 25 MiB / 10,000 个实体写入，允许在一天内完成不超过账户存储上限的首次上传；迁移前账号保留 100 MiB 存储额度。服务端返回每条实体的 `QUOTA_EXCEEDED` disposition，不会静默删除数据。

已登录客户端可读取仅限本账号的 `GET /auth/usage` 聚合配额：总存储已用/上限、当天已上传/上限、当天实体写入数/上限和下一次重置时刻。它不返回实体、其他账号资料或认证凭据；账户概览以此呈现额度，不根据本机待同步数量猜测云端用量。

IP、账号及认证流程的令牌桶保存在数据库事务中，IP 只以 HMAC 派生的桶键和审计主题保存。多个 API 进程连接同一数据库时共享额度。多主机部署必须使用同一个中心数据库或替换为共享 Redis；独立 SQLite 文件不能跨主机协调。

安全事件写入 `security_audit`，配额触发、封禁和受限账号访问同时进入 `security_alerts`。封禁、解封、审计查看和待发送告警必须只通过服务器本机的受控运维入口完成，不暴露 HTTP 管理接口；已移除的 Python `security_admin.py` 不是该入口。

## 兼容性与迁移

这是 API 加法和访问收紧，不修改实体 `syncProtocolVersion`。旧客户端会收到明确 HTTP 错误；应引导用户至账户安全页完成邮箱验证。服务器迁移 12 新增账户状态、资源账本、持久化限流桶和安全审计表。迁移时已存在用户设置 `sync_verified_at=created_at`，新注册用户保持未验证。

公网入口必须在 TLS 终止层之后、API 之前限制请求体、并发连接和单 IP 请求速率；应用层持久化限流是多进程一致的第二道防线。

## 验证

- 新账户未验证邮箱时 `/sync/push` 返回 `EMAIL_VERIFICATION_REQUIRED`；
- 邮箱验证码确认后同步开启；
- 当前实体与同步资产准确计入存储预算；
- 两个进程连接同一数据库时不能绕过令牌桶；
- 封禁撤销令牌，封禁、配额和异常访问存在审计/待告警记录；
- 公网代理配置通过语法校验并对超大请求、连接和突发请求生效。
