# ADR-0027：API v1 路径隔离与产品版本重置

- 状态：已接受
- 日期：2026-08-12

## 背景

历史桌面发行使用过 `v1.0.0` 至 `v1.16.0`，且旧客户端曾访问无版本前缀的同步服务。
产权整改后产品版本重新从 `1.0.0` 开始，仅比较语义版本无法区分历史版本；由于不希望
长期维护客户端世代请求头，服务入口改用明确的 API 路径隔离。

## 决定

1. 新基线产品版本为 `1.0.0`，对用户展示时可简称 1.0。
2. 新客户端仅访问 `/v1/auth/*` 与 `/v1/sync/*`，不发送客户端世代请求头。
3. 历史 `/auth/*` 与 `/sync/*` 在认证、数据库访问和读取请求体之前返回 HTTP 426，
   错误码为 `CLIENT_UPGRADE_REQUIRED`。
4. `/health`、公开更新说明和反馈保持无前缀公开入口；它们不能读写账户同步数据。
5. 用户明确批准一次破坏性服务重置：部署前制作数据库和资产备份，随后清空历史账号、
   令牌、同步实体、反馈及其关联数据，并轮换服务端私有摘要密钥。

## 回滚

代码可回滚到部署前备份，但破坏性数据清空只能从受保护备份恢复。不得重新开放无前缀
认证/同步入口，也不得把真实部署参数或密钥写入仓库。
