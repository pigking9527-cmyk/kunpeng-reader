# ADR-0018：自定义阅读配色与背景图同步

- 状态：已接受
- 日期：2026-08-08

## 决定

阅读偏好的默认主题只随客户端发布，不上传。用户创建的主题使用 `reader_palette_v1` 独立同步实体：每个主题具有稳定的 `custom-` ID，并按既有 LWW 顺序（`updated_at`、`sync_version`、`device_id`）比较；删除必须写入实体墓碑。`reader_palette_order_v1/default` 仅记录主题 ID 的显示顺序，接收端忽略未知 ID。

每个账户最多保留 10 个活跃自定义主题。主题背景图可作为 PNG、JPG、WebP 或 GIF data URL 写在主题实体中；解码后的单张原始图片最大 10 MiB。为容纳 Base64 编码，服务端允许此类实体最多 15 MiB、请求最多 16 MiB，账户实体 JSON 总量最多 150 MiB。服务端和客户端都必须校验这些限制。

## 兼容性

该实体是协议 v1 的可选扩展。旧客户端必须保留未知实体，不得因本地默认主题覆盖或删除它们。默认主题不作为同步实体，因此新增、删除或改名默认主题不会影响跨设备自定义主题。

## 后果

主题图像会增加同步流量与云端存储。同步请求超时使用 60 秒，以允许受限网络传输允许上限内的单张图片；服务端只接受受支持图片 MIME 的 data URL，并拒绝超过主题数量或大小上限的更新。
