# ADR-0012：Android 资讯为本机缓存优先功能

## 状态

已接受。

## 背景

桌面端的 NewsNow 功能包含较大的来源目录、缓存、预取与桌面内嵌文章能力。Android 需要提供阅读器内的资讯入口，但不能把外部聚合服务、用户来源偏好或资讯内容误混入同步数据，也不应在打开书架或资讯页时产生后台网络活动。

## 决定

Android M1 使用固定、小型的 NewsNow 来源目录；用户只能选择预置来源 ID，不能配置聚合服务地址、任意来源 URL 或抓取规则。来源偏好、资讯条目和获取时间保存在应用私有 `news_feed_v1.json`，不写入 `sync_entities`、`book_state_v2`、核心状态迁移包、恢复点或日志。

打开资讯页只读取本机缓存，即使缓存过期也不自动刷新。只有用户明确点击“刷新资讯”或下拉刷新时，客户端才向固定的 HTTPS 公共聚合服务请求所选来源；请求没有认证头、同步 Token、书籍内容、路径、阅读位置或其它用户数据。每个来源请求必须有 12 秒超时、384 KiB 响应上限、40 条条目上限与受限字段长度；最多选择 6 个来源、最终最多显示 180 条。请求、响应、缓存和文章 URL 都必须为 HTTPS 且经结构校验。全量失败时保留上次成功缓存并标记为过期。

资讯正文不在 Android 内嵌 WebView 解析。用户点击条目时只通过系统外链打开已验证的 HTTPS 原文；原生外链桥同样拒绝 HTTP 和含 user-info 的 URL。

## 兼容性、迁移与回滚

这是 Android 本端功能，不修改 `syncProtocolVersion`、服务端 API、同步实体、schema 或 fixture。旧版本没有缓存文件时显示空缓存提示，用户点击刷新后创建 v1 文件。损坏、超限或未知版本缓存按空缓存处理；删除 `news_feed_v1.json` 即可回滚/清除，不影响图书、同步或账户。

## 验证

测试必须覆盖：进入页面/读取缓存零网络调用；仅刷新触发固定 HTTPS 端点；来源选择本机保存且有数量上限；响应 URL/字段/大小限制；去重与排序；过期标记；无网或全失败仍保留旧缓存；以及外链桥拒绝 HTTP。真机还须验证系统浏览器/Custom Tab 的 HTTPS 外链处理和弱网超时体验。
