# ADR-0013：Android 脱敏本机诊断快照

## 状态

已接受（2026-08-07）。

## 背景

桌面端已有本机运行时诊断与阅读问题记录。Android 需要可随 Bug 反馈人工附加的最小等价能力，但诊断导出不能成为书籍、账号、同步凭据或用户反馈文本的旁路。

## 决定

- Android 维护仅进程内的有界诊断环，最多 96 条；应用退出即丢失，不写 SQLite、不进入恢复点、不进入同步实体，也不发网络。
- 当前采样只覆盖同步总阶段、密钥包下载总阶段与同步 HTTP 请求重试。记录字段均为固定枚举与数值：阶段、成功状态、耗时、尝试次数、延迟及有限错误分类。
- 禁止采集或导出 URL、HTTP 响应正文/错误原文、账号/设备/实体/图书标识、书名/正文/标注、路径、URI、反馈文本、API Key、密码、Token 及同步密钥。
- 快照格式为 `kunpeng-reader-android-diagnostics` v1，使用 UTF-8 JSON。导出仍检查 ADR-0008 的 256 KiB 原始附件上限。
- 设置/反馈可以查看、复制或清空本机快照；只有用户在 `Bug` 反馈页点击“附加当前诊断快照”时才将它作为现有的单个 JSON 附件。不得自动附加或上传；功能建议不得附加。

## 兼容性与回滚

这是本端支持材料，不属于同步协议，也不改变 `syncProtocolVersion`、反馈服务 API 或存储权限。移除客户端入口即可回滚；内存数据会随进程退出自然消失。

## 验证

1. 任意长的重试序列只保留最近 96 条，计数器仍累积；
2. 任意采样导出的 JSON 不包含传入的敏感字符串，且尺寸不超过 256 KiB；
3. Bug 页面仅在用户点击后替换现有 JSON 附件；功能建议没有该入口；
4. 未配置反馈端点时快照仍可查看/复制，且不发生网络请求。
