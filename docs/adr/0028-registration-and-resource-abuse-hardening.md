# ADR-0028：注册预验证、设备会话与资源滥用防护

## 状态

已接受。

## 决定

新账号使用两阶段注册：客户端先提交账号名和邮箱到 `POST /v1/auth/register/start`，服务端发送短时验证码；只有 `POST /v1/auth/register/confirm` 同时验证账号名、邮箱、验证码和密码后才创建账号、计算密码 scrypt 并签发会话。旧的 `POST /v1/auth/register` 不再直接创建账号，返回明确的 `REGISTRATION_EMAIL_REQUIRED`。已有账号、邮箱绑定、同步实体和协议版本不改变。

待注册记录只保存规范化账号名、邮箱、服务端密钥 HMAC 后的验证码、尝试次数和过期时间；不保存密码。记录 15 分钟过期，24 小时后清理。账号名与邮箱只在最终事务中占用，竞态由唯一约束处理。

注册同时受 IP、IP 网段、邮箱地址、邮箱域名、每小时全局和每日全局持久化令牌桶限制。全局注册达到保护阈值时拒绝新挑战、写安全告警；管理员可通过服务器外部环境变量临时关闭注册。未完成邮箱验证不会创建账号或消耗账号容量。

认证会话绑定客户端安装 ID。该 ID 来自客户端本机稳定随机值，只用于会话治理，不替代同步实体中的 `device_id`。每账号最多保留 5 个安装设备、每个设备最多一个活动会话，总活动会话仍最多 5 个；登录新设备超过上限时返回 `DEVICE_LIMIT_REACHED`，用户可通过已有设备退出或由运维处理。旧 Token 作为 `legacy` 设备继续兼容，直到自然过期或被替换。

新注册、手机号注册、密码重置和改密统一接受 8–32 个 Unicode 字符的密码；登录既有账户仍保留兼容校验，避免此前的更长密码被无故锁定。

生产 Token、验证码、限流键与审计主题必须使用服务器外部随机 HMAC 密钥。密钥轮换期间读取当前密钥和一个旧密钥；旧 Token 成功使用后立即改写为当前摘要。限流桶无需迁移，旧验证码按 15 分钟自然过期。密钥不得进入仓库、日志、fixture 或客户端。

## 容量与告警

- 新账号默认 25 MiB 持久化存储、每日 25 MiB / 10,000 实体写入；下载恢复不消耗该上传额度，沿用 ADR-0019。
- 注册全局限流、设备上限、密码计算容量、账号总量与配额拒绝形成内容无关安全事件。
- 待发送安全告警继续由服务器本机任务投递，不暴露远程管理 API。
- 未验证挑战数、最近注册数和密码容量拒绝纳入资源监控；不记录原始 IP、邮箱、验证码或密码。

## 兼容与回滚

这是认证 API 的受控收紧，不升级 `syncProtocolVersion`。客户端世代 2 必须使用两阶段注册；登录和已有会话保持兼容。若邮件服务故障，注册明确返回暂不可用，不能退回“先创建未验证账号”。回滚时可以暂时关闭注册，但不得恢复无邮箱验证的直接创建。

## 验证

- 未确认验证码时用户表、Token 表和密码哈希均不新增；
- 注册挑战限流在两个 API 进程之间共享；
- 错误验证码有尝试上限，过期挑战不能使用；
- 同一邮箱只能创建一个账号；
- HMAC 轮换后旧 Token 可使用并被惰性迁移；
- 第 6 台设备登录被拒绝，已有设备与同步不受影响；
- 桌面注册页必须收集邮箱、发送验证码、确认后才保存登录状态；
- 密码、Token、验证码、原始邮箱和 IP 不进入日志或测试夹具。
