# ADR-0005：同步的书库问答记录

## 状态

已接受。

## 背景

书库问答可跨整座书架、单书深度检索或跨书对比。用户需要在本机回看已完成的回答，并在已登录的其他设备继续查看同一批记录；但同步范围不能包含书籍正文、语义索引或机器本地的书籍 ID。

## 决定

复用可选实体 `ai_reader_history_v1`，新增稳定记录 `ai_reader_history_v1/library-v1`。本机书库问答历史不设活跃记录上限；上传时才物化为最多 100 条按时间倒序的记录。其 payload 为 `version: 1`、`scope: "library"`，每条记录仅包含：

- 稳定记录 ID、问题、回答、问答模式与生成时间；
- 最多 20 个来源的书名、章节号与材料类型（目录、正文开篇或正文检索）。

不得写入或同步来源原文片段、书籍文件、本机 `bookId`、本机路径、向量、嵌入、API Key 或模型输入。问答始终先本机保存。书库问答在自身设置页提供三种独立模式：`off` 只保存本机；`recent` 自动上传最近 100 条；`manual` 仅上传用户对单条记录明确选择“云端”的回答，选择数量最多 100 条。手动模式的云端标记会随本机记录保存，并在下载云端快照后按该快照回写；取消云端标记或删除记录会在下一次同步更新云端快照。单书智读历史同样提供最近自动同步与手动选择两种模式（总开关仍可关闭它）；提问、总结和脑图共用账号级 100 条活跃记录额度，绝不按单本书重复计算。用户删除单条记录时，payload 保留仅含 `id` 与 `deletedAt` 的条目墓碑；墓碑不含问题、回答、书名或正文，用于防止其他设备的旧本地缓存复活已删除记录。

## 兼容性

该实体仍是协议 v1 的可选扩展，不改变 `syncProtocolVersion`。旧客户端可忽略 `library-v1`，服务端照常保存、拉取与保留；新版客户端按稳定记录 ID 合并，并让条目墓碑优先于同 ID 的旧记录。实体级冲突仍使用既有 LWW，后续同步会将书库与单书智读本机历史分别投影为最多 100 条活跃云端记录及最多 200 条删除墓碑再上传。单书智读的最近模式按账号跨所有图书、所有智读任务统一取最新 100 条；手动模式也在同一账号级额度内累计。书库问答另有独立的 100 条上限。

## 验证

客户端测试覆盖本地保存、智读与书库问答各 100 条上限、账号跨书筛选、敏感来源字段剔除与关闭同步开关时的墓碑；前端测试覆盖自动保存、问答记录入口及同步提示。服务端既有允许名单继续接受 `ai_reader_history_v1`，并仅对此实体开放 4 MB 的单实体上限。
