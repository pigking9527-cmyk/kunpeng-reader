# ADR-0005：同步的书库问答记录

## 状态

已接受。

## 背景

书库问答可跨整座书架、单书深度检索或跨书对比。用户需要在本机回看已完成的回答，并在已登录的其他设备继续查看同一批记录；但同步范围不能包含书籍正文、语义索引或机器本地的书籍 ID。

## 决定

复用可选实体 `ai_reader_history_v1`，新增稳定记录 `ai_reader_history_v1/library-v1`。其 payload 为 `version: 1`、`scope: "library"` 与最多 100 条按时间倒序的记录。每条记录仅包含：

- 稳定记录 ID、问题、回答、问答模式与生成时间；
- 最多 20 个来源的书名、章节号与材料类型（目录、正文开篇或正文检索）。

不得写入或同步来源原文片段、书籍文件、本机 `bookId`、本机路径、向量、嵌入、API Key 或模型输入。问答始终先本机保存；只有用户开启“同步智读历史”后，才在下一次同步上传并合并远端记录。关闭该开关维持既有私密同步语义：向服务端发送历史实体墓碑，不再保留云端副本。用户删除单条记录时，payload 保留仅含 `id` 与 `deletedAt` 的条目墓碑；墓碑不含问题、回答、书名或正文，用于防止其他设备的旧本地缓存复活已删除记录。

## 兼容性

该实体仍是协议 v1 的可选扩展，不改变 `syncProtocolVersion`。旧客户端可忽略 `library-v1`，服务端照常保存、拉取与保留；新版客户端按稳定记录 ID 合并，并让条目墓碑优先于同 ID 的旧记录。实体级冲突仍使用既有 LWW，后续同步会把合并后的 100 条活跃记录及最多 200 条删除墓碑重新物化并上传。智读侧的 100 条是账号跨所有图书的云端合计上限，书库问答另有独立的 100 条上限。

## 验证

客户端测试覆盖本地保存、智读与书库问答各 100 条上限、账号跨书筛选、敏感来源字段剔除与关闭同步开关时的墓碑；前端测试覆盖自动保存、问答记录入口及同步提示。服务端既有允许名单继续接受 `ai_reader_history_v1`，并仅对此实体开放 4 MB 的单实体上限。
