# 测试版 1.1 修订版（1.1.0-beta.4）

这是面向早期开发验证的三平台预发布包。

## 本次修正

- 修复 Linux 干净构建环境中离线更新说明的发布入口断言，确保 Rust 发布前测试通过后才会打包。
- 保留 beta.3 的 Linux 缓存顺序修正：恢复构建缓存后再生成许可证清单，避免打包阶段读取不到该文件。

## 安装与边界

- Windows 提供便携版、NSIS 安装包和 SHA-256 清单。
- Linux 提供 AppImage、Debian 包和 SHA-256 清单。
- macOS Apple Silicon 提供 App ZIP、DMG 和 SHA-256 清单；本次是临时签名、**未公证**的早期开发包。
- 三个平台均由同一个 `v1.1.0-beta.4` 源码标签构建。仅当相应工作流和安装包结构校验完成后，文件才会添加到 GitHub 预发布页。

beta.2 与 beta.3 均未形成完整的已验证三平台资产；请使用本修订版。
