# 测试版 1.1 修订版（1.1.0-beta.2）

## 发布范围

此修订候选包含测试版 1.1 之后的桌面端修复，重点包括阅读器跨章排版和脚注稳定性、macOS 同步凭据持续授权与已保存同步地址恢复，以及资讯中心、设置和阅读体验的近期改动。

## 打包修复

`1.1.0-beta.1` 的部分安装包在项目存在多个可执行目标时没有显式选择阅读器主程序，导致 macOS 包误收录了无阅读窗口的辅助进程。该候选在以下三个层级固定目标为 `ebook-reader-tauri`：

1. Cargo 只把 `src/main.rs` 声明为可自动打包的桌面二进制；
2. Tauri 配置指定同一主程序名称；
3. 三个平台工作流向构建器显式传入该二进制。

macOS 还会校验 App ZIP 与 DMG 中的 `CFBundleExecutable` 和可执行文件；Linux 会校验 AppImage 与 deb 的主程序；Windows 便携版会校验主程序存在且体积合理。

## 旧包处理

不要继续安装 `1.1.0-beta.1` 的 macOS ZIP、DMG、Windows NSIS 安装包或 Linux deb。它们不是已验证的阅读器安装包。Windows 便携版没有走错误的打包路径，但仍建议统一改用经完整验收的修订候选。

## 发布边界

这是早期开发预发布。仓库所有者已确认历史许可证整改、资产处置和复核完成；每个资产仍通过发行包许可证与知识产权检查。

macOS Apple Silicon 包使用临时签名，尚未完成 Developer ID 签名或 Apple 公证。首次打开可能需要在 macOS 的安全提示中手动确认；不应将它视为稳定版或生产环境安装包。
