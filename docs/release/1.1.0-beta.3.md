# 测试版 1.1 修订版（1.1.0-beta.3）

`1.1.0-beta.2` 未上传任何已验证资产：Linux 构建在打包前发现恢复构建缓存覆盖了许可证清单，已安全停止。此修订把 Linux 缓存恢复提前到许可证清单生成之前，保证 Rust 的桌面资源打包能读取当前构建的第三方声明。

本版包含 `1.1.0-beta.2` 的全部阅读器主程序打包修复和近期桌面端改动。Windows、Linux 与 macOS Apple Silicon 都从同一源码标签构建，并检查安装包中存在 `ebook-reader-tauri` 阅读器主程序。

这是早期开发预发布。macOS Apple Silicon 包使用临时签名，尚未完成 Developer ID 签名或 Apple 公证；首次打开可能需要在 macOS 的安全提示中手动确认。请不要继续使用 `1.1.0-beta.1` 的安装包。
