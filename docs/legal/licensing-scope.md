# 许可证范围

## 第一方代码

除文件或目录明确另行说明外，本仓库中的第一方代码，包括根 Rust 应用、`reader-core/`、`crates/epub-parser/`、`apps/`、`packages/`、`ui/` 与服务端代码，统一受根目录 [`LICENSE`](../../LICENSE) 的 Kunpeng Reader Source-Available License 约束。

Cargo 与 npm 清单中的 `license-file` / `SEE LICENSE IN` 只是把该统一范围机器可读化；它们不把私有包发布到公共注册表，也不额外授予 MIT、GPL 或其他开源权利。

## 第三方材料

依赖、PDF.js、词典数据、频率数据、模型、字体、图片及平台运行库仍由各自许可证约束。仓库内可分发材料的归属与条款入口集中在 [`THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md) 和 `LICENSES/`；构建系统必须把这两者加入桌面发行包。

动态下载但没有随安装包分发的字体和模型不因下载功能而变成第一方代码；客户端必须在下载前保留来源和许可证入口。

## 贡献与重新许可

贡献代码不会因为提交到公开仓库而自动变成 MIT 或公共领域。接受外部贡献前，应取得与根许可证一致的贡献授权或单独的版权许可。涉及第三方代码替换、双许可或例外授权时，必须把书面依据保存在仓库外的受控法律档案中，仓库只记录不含隐私的许可结论。
