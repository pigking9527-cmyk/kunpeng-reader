# 鲲鹏阅读器（Kunpeng Reader）

**中文** | [English](README.en.md)

[**查看三平台测试构建状态（Windows / macOS / Linux）**](https://github.com/pigking9527-cmyk/kunpeng-reader/actions)

一个面向 Windows、macOS 与 Linux 的高性能本地电子书阅读器。桌面端使用 **Rust + Tauri 2 + 系统 WebView**，书架与阅读页相互独立、EPUB 原生渲染、按章/虚拟小章按需加载，大书打开更快。

> 当前桌面版本为 **测试版 1.1**（技术版本 `1.1.0-beta.1`）。项目地址：[github.com/pigking9527-cmyk/kunpeng-reader](https://github.com/pigking9527-cmyk/kunpeng-reader)。安装包会发布到对应的 GitHub 预发布页；版本沿革与当前测试边界见[开发记录](开发记录.md)及[开发沿革](docs/history/v1.16-to-beta-1.0-development-evolution.md)。

## 特性

**阅读**
- **多格式**：EPUB / PDF / TXT / Markdown / MOBI / AZW / AZW3，批量导入、封面墙、拖拽导入、更换封面、**多目录自动导入**
- **评分**：书籍信息里五星打分（**支持半星**），书架可**按评分过滤**，评分小星可叠在封面上
- **标签与书单**：右键图书即可添加、移除和管理标签/书单；书单支持简介、封面和拖动排序，漏斗面板支持多选过滤，分类会随图书轻数据同步
- **EPUB**：CSS 多栏按章/虚拟小章分页，超大章节使用快速分页与批量布局；支持目录/虚拟章节、整页单页/双页、滚动模式连续阅读与单击整页翻页、书签、书内搜索、脚注就地弹窗、主题（浅/深/护眼）、字体/字号/行距/边距随心调；可按需下载霞鹜文楷 Lite、思源宋体和朱雀仿宋，下载后离线使用
- **翻页体验**：整页模式支持单页/双页显示；滚动模式保持真实连续滚动，同时支持鼠标/键盘按虚拟页片段翻页；整页动画收敛为新旧页面同步左移的水平翻页，跨章衔接不再回闪
- **PDF（PDF.js 自渲染）**：连续滚动、文字层选择、内置目录、缩放（适配窗口 + 细粒度）、**双页模式**、PDF 内搜索、PDF 高亮/批注、记住缩放/双页
- **TXT**：网文按「第X章」自动切章建目录，百万字大文件虚拟化加载、秒开
- **高亮 / 批注**：选中即高亮或批注；高亮菜单可用横排/九宫格布局、四种颜色和百度/Google web 搜索；多行及跨页选区会把菜单稳定放在可操作位置；大批注页统一管理
- **智读（BYOK）**：在划词菜单打开右侧阅读助手，对已经读到的内容提问、总结或生成可视化脑图，并保存本机问答历史；支持 DeepSeek、OpenAI、Anthropic 及 OpenAI 兼容接口
- **沉浸模式**：隐藏工具栏、点屏幕中间唤出，切换零重排不跳页
- **朗读（TTS）**：逐词高亮 + 自动翻页；系统语音（离线）或在线·微软神经（edge-tts，免费 Azure 级中文音色）
- **词典 / 生词本**：划词或高亮文字可离线查词，内置中文维基词典、CC-CEDICT 与 ECDICT，支持**中中 / 中英 / 英中 / 英英**释义切换；可导入 TSV / CSV / JSON、StarDict 和常见未加密 MDX 外置词典，按优先级先查外置词典再查内置词典；查过的词自动进入生词本，可按查询时间或次数排序，并可隐藏/显示查询次数
- **跨书搜索**：阅读页划词菜单可直接跨全书架（包含当前书）搜索选中文字或句子，按书分组展示结果，支持折叠、分批展开和跳回来源书页
- **划词翻译**：阅读页划词菜单支持翻译大段文字，预留并接入 DeepL / Google / 百度 / 腾讯翻译配置，用户可自行填写 API 凭据

**书库问答（RAG / BYOK）**

- **整库或单书问答**：面向整座书架、标签、书单、手选范围或指定图书检索，支持多书对比和单书深度回答
- **引用与分类**：回答附带可预览、可跳回原书的脚注来源；大模型分类标签可辅助范围筛选和结果排序
- **模型、历史与隐私**：支持 DeepSeek、OpenAI、Claude 及兼容接口；历史默认保存在本机，仅在用户开启后同步脱敏问答，不上传正文、原文件、路径、语义索引或明文 API Key

**资讯（Windows）**

- **资讯流与正文**：按类别和来源浏览横排 / 方格资讯流；文章在阅读器内显示清理后的标题、正文、图片、来源与发布时间
- **缓存与预取**：打开时优先使用本地缓存，可选后台预取；封面按进入视野的卡片懒加载

**情报中心（Windows，测试）**

- **综合简报**：从公开来源目录分批收集资讯，在本机去重、合并同一事件、排序并整理主题要点；完整资料库建立后轮换来源做增量更新
- **证据可追溯**：简报、关联信号和候选条目可直接打开清理后的资讯正文，并保留原始来源入口；资料快照仅保存在本机，不上传书库，也不调用外部模型
- **多视图研究**：提供综合简报、监测、研究和星际旅行视图；星际视图只筛选相关候选信号并展示人工基线，不会自动把新闻计入进度

**检索**
- **书架全文检索**：压缩逐章文本索引 + Bloom 预筛选 + 有界 LRU 缓存 + 多线程字节级 `memmem`；保留精确扫描兜底，兼顾速度与结果完整性
- **语义检索**：`bge-small-zh-v1.5`（fastembed / ONNX，离线）向量嵌入；合并多中心画像 + 分片 HNSW 近邻索引，兼容并自动迁移旧版语义画像/HNSW；主设置页可管理模型、语义索引和加速索引

**统计与其它**
- **鼠标手势（桌面端）**：在“常用设置 → 手势”中开启和管理；左键录制、右键拖动执行，可配置返回/关闭、信息提取/说明和重新打开上一页面。
- **手势识别与精度**：按归一化形状和方向顺序匹配，不要求总距离或各段长度比例一致；支持全局/独立 1～10 档精度及自定义提示样式。
- **详细阅读统计**：日 / 月 / 年 / 总四视图，时长、字数、读过/读完、高亮/批注，阅读贡献热力图与 SVG 图表；可切换时间 / 字数、柱状图 / 折线图和热力图配色，统计项目显示偏好会保留
- **账号与同步**：支持注册 / 登录，将阅读进度、高亮、批注、生词本、阅读统计、设置等轻数据同步到服务器；同步游标、统计和确认基线按“标准化服务器地址 + 账号”隔离，切换账号后不会复用另一账号的同步状态；账号状态会在启动时恢复并自动同步，退出前执行有界同步
- **数据与隐私**：设置中可分别清除本设备数据、清除本设备及云端数据或永久删除账号；云端清除会提升数据世代并撤销旧令牌，避免离线旧设备把已清数据重新同步回来；三种操作均不删除用户自行导入的原始书文件
- **本地 SQLite 数据层**：轻数据统一写入 SQLite，启用 WAL 自动 checkpoint、日志大小治理和 v2 可移植实体模型；旧数据库会安全压缩迁移
- **恢复点与数据包**：每日自动创建恢复点（最多 7 个），支持手动备份；恢复事务 v2 使用文件大小和 SHA-256 清单、只打开既有数据库的完整性验证与崩溃幂等回滚，数据包导入前自动备份并立即应用
- **运行时可靠性**：Windows 使用系统互斥量、macOS / Linux 使用文件锁保证单实例并转发待打开图书；备份和恢复进入全局数据维护临界区；可续建后台任务只在耐久检查点成功落盘后推进，语义索引按完成一本书的边界保存进度
- **页数缓存**：全书页数按版式逐章增量统计并复用；智读侧栏只临时压缩正文，不会清空缓存或重复统计，双页模式仍按物理单页显示总页数
- **高频词语音包**：可在本机生成前 10,000 高频英文词语音缓存，支持暂停、继续、进度显示和删除
- **「我的书架」显示设置**：封面是否显示阅读进度 / 评分 / 书名，各自开关；网格视图可只显示封面，筛选面板可保持默认自适应或指定封面列数
- **新版提示**：启动后台优先检查 GitHub 最新发行版，连接失败时走服务器更新清单兜底；「关于」里可手动检查更新、看本版更新内容
- **稳定发布流程**：GitHub Actions CI 与本地固定检查脚本共用 `scripts/check.ps1`，覆盖测试、UTF-8、版本一致、图标、安全基线和 CSS；release 构建脚本自动校验图标并刷新 Windows 图标缓存；GitHub Release 同时发布 Windows 单文件绿色版/安装包、macOS Apple Silicon DMG/App ZIP、Linux AppImage/deb 与各平台 SHA-256 校验清单
- 划词 web 搜索、独立窗口（EPUB 与 PDF 各自记忆几何）、关于页

> 智读采用用户自备 API Key。接口配置经系统能力保护后仅保存在本机，不进入同步实体；发送内容限制为当前书已经读到的相关章节和用户明确选择的文字。

更多细节见 [开发文档.md](开发文档.md)；版本变更见 [开发记录.md](开发记录.md)。

## 构建

### Windows

日常检查：

```powershell
cd ebook-reader-tauri
powershell -ExecutionPolicy Bypass -File scripts/check.ps1
```

GitHub Actions 会在 `main` 的 push / pull request 上自动运行同一套检查。

提交与发布前的资料安全流程见 [仓库资料安全流程](docs/security/repository-safety.md)。首次克隆请安装提交钩子；发布时必须用 `scripts/stage-release.ps1` 暂存明确的发布文件，禁止“暂存全部”。

发布构建（生成 release exe、将运行文件更新到项目根目录、在桌面创建快捷方式、校验图标并刷新 Windows 图标缓存）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-release.ps1
```

完整发布（检查、绿色版、NSIS 安装包、tag、GitHub Release 和资产上传）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/release.ps1
```

安装包：

```powershell
cargo tauri build
# 安装包输出：target/release/bundle/nsis/
```

- 单文件绿色版：`target/release/ebook-reader-tauri.exe`；ONNX Runtime 已静态链接，本机运行文件为项目根目录的 `鲲鹏阅读器.exe`，桌面仅创建 `鲲鹏阅读器.lnk` 快捷方式
- 安装包：`target/release/bundle/nsis/`

### Linux x86_64

GitHub Actions 的 `Linux x86_64 build` 工作流使用 Ubuntu 24.04 构建并验证以下产物：

- `Kunpeng-Reader-v<版本>-Linux-x86_64.AppImage`
- `Kunpeng-Reader-v<版本>-Linux-x86_64.deb`
- `SHA256SUMS-Linux.txt`

AppImage 下载后需要增加可执行权限：

```bash
chmod +x Kunpeng-Reader-v*-Linux-x86_64.AppImage
./Kunpeng-Reader-v*-Linux-x86_64.AppImage
```

Ubuntu / Debian 也可以安装 deb：

```bash
sudo apt install ./Kunpeng-Reader-v*-Linux-x86_64.deb
```

当前语义搜索运行库要求 glibc 2.38 或更高版本，因此 Linux 首发兼容基线是 Ubuntu 24.04 x86_64。Linux 产物已通过链接检查和虚拟显示环境启动烟测，但尚未签名；Ubuntu 22.04、Debian 12 及其他发行版仍需单独验收。

## 技术栈

Rust · Tauri 2 · WebView2 / WKWebView / WebKitGTK · 自定义 URI 协议（按章/资源虚拟化）· fastembed(ONNX) · instant-distance(HNSW) · PDF.js · tokio-tungstenite(edge-tts)。
